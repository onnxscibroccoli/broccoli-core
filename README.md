# Organic Problem Solver

Broccoli Core now supports a provider-agnostic problem solving pipeline.

```
User Goal
      │
      ▼
Problem Runtime
      │
      ▼
Evidence Collectors
      │
      ▼
Reasoners
      │
      ▼
Remediation Planner
      │
      ▼
Workflow Engine
      │
      ▼
Verification
      │
      ▼
Knowledge Learning
```

Future collectors should publish evidence rather than directly solving problems.
