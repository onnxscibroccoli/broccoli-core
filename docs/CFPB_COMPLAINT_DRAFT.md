# CFPB Complaint Draft — xAI / SuperGrok Billing Separation

**Portal:** https://www.consumerfinance.gov/complaint/
**Company:** xAI (or SpaceXAI / X Corp — select whichever appears; if not listed, enter contact info)
**Product:** Subscription / recurring payment (SuperGrok)
**Issue type:** Deceptive or misleading practices; unexpected charges; dark patterns

---

## Narrative (paste into the text box)

I am a paying SuperGrok subscriber. I was led to believe my subscription covers access to Grok models. When I attempted to use the xAI API (api.x.ai) with a generated API key, I was required to purchase separate prepaid credits — a second, distinct billing ledger that was not clearly disclosed at the time of purchase.

This is a deceptive separation of products. The consumer experience presents SuperGrok as a single paid tier for Grok access, yet the API surface (the only programmatic way to integrate the models into third-party tools) demands additional payment. This constitutes an unfair and deceptive practice under the Consumer Financial Protection Act and the CFPB's January 2023 circular on negative-option / dark-pattern subscription marketing.

I am requesting:
1. Full refund of any credits purchased under this misunderstanding.
2. Clear, conspicuous disclosure at purchase that API access requires separate billing.
3. OAuth-based access that honors the SuperGrok subscription without additional charges.
4. Written confirmation that the subscription and API ledgers will be unified or clearly separated in future marketing.

Supporting documents attached: subscription confirmation email, API error screenshots, and the project's public issue tracker (github.com/onnxscibroccoli/broccoli-core/issues/17).
